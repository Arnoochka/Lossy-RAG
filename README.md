# Хранение и поиск эмбеддингов в СУБД для LLM

## Общая идея
  RAG-система позволяет модели эффективно работать с большими объемами контекста, извлекая наиболее релевантную
информацию. Это обеспечивает сохранение высокого качества ответов без необходимости обрабатывать весь контекст целиком. Данный подход снижает вычислительные затраты и накладные расходы, повышая эффективность использования ресурсов. 

#### Идея нашего проекта в исследовании и тестировании RAG системы и связанных с ней методов и моделей. 

### План исследования:
#### Stage 1 (Елена)
1. Принцип работы эмбеддинг-моделей: преобразование текста в векторы и оценка семантической близости.
2. Сравнение моделей разных размеров и методов снижения размерности векторов (PCA, Matryoshka).
#### Stage 2 (Виктор)
3. Методы ускорения поиска: IVF, HNSW, BM25 и квантизация векторов: скалярные, векторные, бинарные.
#### Stage 3 (Кирилл)
4. Выбор SOTA моделей и их запуск, подготовка и обработка датасета.
5. Оценка влияния использования RAG системы на точность ответов модели.
