# Заметки Lossy-RAG

Здесь собраны теоретические заметки по квантизации эмбеддингов и приближённому поиску. В них разобраны математика методов, алгоритмы построения индексов и источники ошибки.

## Квантизация

Полный конспект — [NOTES_quant.md](NOTES_quant.md).

- [SQ](NOTES_quant.md#sq--scalar-quantization) — равномерная сетка уровней и границы ошибки восстановления.
- [PQ](NOTES_quant.md#pq--product-quantization) — разбиение вектора на группы координат и обучение кодовой книги для каждой группы.
- [OPQ](NOTES_quant.md#opq--optimized-product-quantization) — подбор ортогонального преобразования перед PQ.
- [AQ](NOTES_quant.md#aq--additive-quantization) — восстановление вектора суммой представителей из нескольких кодовых книг.
- [BQ](NOTES_quant.md#bq--binary-quantization) — кодирование знаков координат и ошибка восстановления.
- [RaBitQ](NOTES_quant.md#rabitq) — бинарный код после случайного поворота, поправка к скалярному произведению и вероятностная граница ошибки.
- [Расчёт памяти](NOTES_quant.md#аналитический-расчёт-памяти) — объём кодов и параметров каждого метода.

## Поиск

Полный конспект — [NOTES_search.md](NOTES_search.md).

- [IVF](NOTES_search.md#ivf--inverted-file-index) — построение списков по кластерам, выбор кандидатов и стоимость поиска.
- [IVF + RaBitQ](NOTES_search.md#ivf--rabitq) — кодирование остатков относительно центроидов и отбор кандидатов на точный пересчёт.
- [HNSW](NOTES_search.md#hnsw--hierarchical-navigable-small-world) — построение многоуровневого графа, обход его уровней и параметры поиска.

Описание проекта и план экспериментов — [README.md в корне репозитория](../README.md).
