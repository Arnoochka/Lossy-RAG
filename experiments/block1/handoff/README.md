# Передача данных для блоков 2 и 3

Отдельный архив данных распаковывается в корень репозитория. Он содержит:

- пять полных таблиц SQuAD и `dataset_manifest.json`;
- `data/embeddings_bge-small-en-v1.5/chunk_embeddings.npy`: 82 222 × 384 float32;
- `chunk_ids.npy`: точное соответствие строк матрицы `chunk_id`;
- `query_embeddings.npy`, `query_ids.npy`: основные 500 исходных train-запросов;
- `exact_top10_chunk_ids.npy`, `exact_top10_scores.npy`: воспроизведённый точный baseline;
- `manifest.json`: модель, префикс, нормировка, выборка и SHA256 каждого массива.

Эти имена уже используются `jupyter/stage2_quant.ipynb` и `jupyter/stage2_search.ipynb`.
Открывать эти ноутбуки с текущей папкой `jupyter/`.
Для проверки — `python experiments/block1/scripts/audit_release.py` из корня.

500 пар для проверки устойчивости переключаются через `scripts/prepare_block2.py --sample paraphrase`.
При переключении скрипт проверяет точную выдачу, обновляет метаданные и убирает кэши других k,
которые иначе могли бы относиться к старой выборке. Вернуться можно через `--sample main`.

Вопросы valid присутствуют в CSV, но их эмбеддинги в архив не включены.
Base/Large/Nomic документы также отсутствуют. `bge_small_manifest.json` — контрольные суммы
исходной поставки Small с основными 500 запросами; переключение выборки меняет локальный manifest.

Документные векторы были предоставлены как промежуточные, но их совместимость с финальными
Small-метриками и сохранёнными 500 парами подтверждена повторным точным поиском 18.11.2026.
