## Основные результаты

| Модель | Размерность | Strict Hit@5, основные 500 |
|---|---:|---:|
| BGE Small | 384 | 81,2% |
| BGE Base | 768 | 85,0% |
| BGE Large | 1024 | 84,6% |

Эти различия наблюдаются в выборке. После Холма на 31 сравнение с Small статистическое
превосходство Base и Large не подтверждено (p=0,12071 и 0,27008).
Nomic Matryoshka численно выше PCA на четырёх размерностях; после Холма различия также незначимы.

Для отдельной выборки 500 пар strict Hit@5 оригинал → перефраз:
Small 82,0% → 68,4%; Base 86,0% → 74,8%; Large 87,0% → 78,0%.
Снижение у каждой модели значимо после Холма; различия устойчивости между моделями — нет.
Не смешивать эти 500 пар с основной выборкой из 500 вопросов или малым пилотом из 11 перефраз.

## Как проверить

Из корня репозитория, Python 3.12:

```bash
python -m pip install -r experiments/block1/requirements-block1.txt
python experiments/block1/scripts/verify_manifest.py
python experiments/block1/scripts/audit_release.py --tables-only
```

После распаковки отдельного архива данных в корень проекта:

```bash
python experiments/block1/scripts/audit_release.py
```

Отчёты нового запуска записываются в `local_checks/`; опубликованные таблицы сохраняются.
Архив данных содержит `data/*.csv` и `data/embeddings_bge-small-en-v1.5/`.
Они исключены из Git. Код, таблицы результатов, графики и отчёты входят в Git-пакет.
